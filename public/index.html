Local setup

Required environment variables before starting the server.

.env

          

          
The app reads JWT_SECRET, MONGO_URI,
            LIBRARIAN_EMAIL, and LIBRARIAN_PASSWORD on startup. JWT_SECRET must
            be at least 32 characters long.
          

        


        

          

            
Authentication

            
Send the token in the Authorization header.

          

          

            
01 / ACCOUNT
              
Register or sign in

              
Register creates a member account. Librarian accounts are configured by the server owner.

            

            
02 / TOKEN
              
Keep the access token

              
Use the token from the response for every protected request.

            

            
03 / REQUEST
              
Call a protected route

              
Add Authorization: Bearer <token> to the request headers.

Responses & errors

            
All API responses use JSON unless a request succeeds with HTTP 204.

          

          

            
200 / 201 · Success
              
Successful reads and updates return the resource. Created accounts, books, and borrow requests return
                201.

            

            
400 / 404 · Request issue
              
Malformed input or IDs return 400. A valid ID with no matching record returns 404.

            

            
401 / 403 · Access denied
              
Missing or invalid token returns 401. A valid account without the required role returns 403.

            

            
409 · Conflict
              
Duplicate entries, unavailable stock, or an invalid request-state transition return 409.
